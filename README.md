# 💼 IT Expenditure Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive IT Expenditure Dashboard developed using Microsoft Power BI to analyze IT financial performance across business areas, IT areas, countries, and cost elements.

The dashboard compares actual expenditure, forecast expenditure, and planned costs to monitor financial performance, evaluate budget variances, and support data-driven decision-making.

## 🎯 Business Objectives

- Monitor IT expenditure against planned and forecast costs.
- Analyze financial variances between plan, actual, and forecast values.
- Understand expenditure distribution across business areas and IT areas.
- Identify country-wise financial variance patterns.
- Track monthly IT expenditure trends.
- Support financial planning and cost management.

## ✨ Dashboard Features

- Interactive dashboard with business area and IT area filters.
- Monthly comparison of Actual, Forecast, and Plan expenditure.
- Business area-wise expenditure analysis.
- IT area-wise expenditure analysis.
- Cost element-wise variance analysis.
- Country-wise Plan vs Actual Variance reporting.

## 🔍 Key Analysis

- Compared actual, forecast, and planned IT expenditure across months.
- Analyzed expenditure distribution across business areas and IT areas.
- Examined cost element contributions to Plan vs Actual Variance.
- Evaluated country-wise financial variance.
- Developed KPI-based reporting to monitor IT financial performance.
